# Executive Brand-Voice Copilot

مساعد تنفيذي يحوّل ملاحظات الاجتماعات غير المنظمة إلى قرارات وبنود عمل وإيميل رسمي مدقق بنبرة مؤسسية محددة، بالاعتماد على قاعدة معرفة الشركة (RAG).

## كيف يعمل
1. **الاسترجاع (Retrieval):** يبحث في `knowledge_base/` عن أدلة النبرة والقوالب والسياسات الأقرب للاجتماع (FAISS + FastEmbed).
2. **التوليد المعزز:** يمرر المقاطع المسترجعة مع الملاحظات إلى نموذج Groq عبر سلسلة LangChain واحدة.
3. **المخرجات:** ملخص ومهام، مسودة إيميل، تقرير تدقيق، المصادر المستخدمة، وحفظ السجل في SQLite.

## التشغيل محلياً
```
pip install -r requirements.txt
export GROQ_API_KEY="مفتاحك"
streamlit run app.py
```

## النشر على Streamlit Cloud
ضع المفتاح في Settings ثم Secrets:
```
GROQ_API_KEY = "مفتاحك"
```

## الملفات
- `app.py`: التطبيق (RAG + الواجهة + قاعدة البيانات)
- `knowledge_base/`: وثائق الشركة المستخدمة في الاسترجاع
- `requirements.txt`: المكتبات المطلوبة
